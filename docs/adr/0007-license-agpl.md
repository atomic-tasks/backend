# 0007. Лицензия AGPL-3.0

Статус: принят

## Решение
Бэкенд и клиенты под AGPL-3.0-only: любой, кто запускает изменённую версию как сервис, обязан открыть код.

## Последствия
Совместимо с зависимостями (MIT, Apache-2.0, BSD). Форкам на AGPL сложно публиковаться в App Store —
к автору это не относится. Без CLA сменить лицензию после внешних контрибуций будет нельзя.
