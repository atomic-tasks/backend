# 0003. Приоритет как произведение весов

Статус: принят

## Контекст
Важность задачи зависит от важности всех папок над ней.

## Решение
Вес у каждой папки и задачи в диапазоне 0.5–2.0, по умолчанию 1.0.
Приоритет = произведение весов от выбранной папки до задачи.

## Последствия
Нейтральная папка (1.0) не влияет на порядок, глубина вложенности сама по себе не даёт преимущества.
Внутри одной папки порядок не зависит от весов предков, поэтому режим «проводник» обходится без рекурсии.
