# 0002. Дерево: adjacency list в двух таблицах

Статус: принят

## Контекст
Произвольная вложенность «папка в папке», задачи в папках. Запись частая (агент), объёмы личные (тысячи строк).

## Решение
`folders.parent_id` (adjacency list) + `tasks.folder_id`. Поддеревья — рекурсивный CTE.
Nested set отклонён: дорогие вставки и переносы. Closure table и materialized path — избыточны на старте.
Две таблицы вместо одной `nodes`: задача физически не может стать родителем.

## Последствия
Перенос папки — смена одного `parent_id`, но нужна проверка на цикл.
Если чтение станет медленным (>50 мс), кэшировать эффективный приоритет у задачи.
