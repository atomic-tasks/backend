# 0006. MCP внутри FastAPI-приложения

Статус: принят

## Решение
MCP-сервер (официальный SDK `mcp`, `MCPServer`, Streamable HTTP, stateless) монтируется в то же
ASGI-приложение на `/mcp`. Один образ, один процесс, общий контейнер dishka.

## Последствия
Простой деплой. MCP и REST масштабируются вместе — для текущих нагрузок это плюс.
