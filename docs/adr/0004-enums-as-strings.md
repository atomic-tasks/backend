# 0004. Енамы в Postgres — строки без constraint

Статус: принят

## Решение
Статусы и прочие перечисления хранятся как `String` без CHECK-constraint и нативных enum.
Валидирует домен (`StrEnum`).

## Последствия
Новое значение не требует миграции. Запись в БД в обход приложения может положить мусор — приемлемо.
