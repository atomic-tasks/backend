# 0001. Чистая архитектура и именование слоёв

Статус: принят

## Контекст
Один набор бизнес-правил обслуживает несколько входов: REST для веба, Flutter и бота, MCP для агентов.

## Решение
Слои `domain` → `application` → `infrastructure` / `presentation`, composition root в `config/`.
Сценарии — сервисы по агрегату, чтение деревьев — отдельный `TreeService`.
Папки адаптеров называются по технологии: `postgres`, `fastapi`, `mcp`.
DI — dishka. Границы слоёв проверяет import-linter.

## Последствия
FastAPI и MCP остаются тонкими, правила не дублируются. Сервисы нужно следить, чтобы не разрастались.
