# 0005. Многопользовательская модель с первого дня

Статус: принят

## Решение
`owner_id` во всех таблицах, составные индексы с `owner_id` первым.
Доступ проверяется только через порт `AccessPolicy`. ID — UUIDv7.
Шаринг папок не реализуем, но модель его не исключает.

## Последствия
Добавить шаринг = таблица `shares` и новая реализация `AccessPolicy`, без переписывания сервисов.
Личные веса для гостей потребуют отдельной таблицы настроек пользователя.
