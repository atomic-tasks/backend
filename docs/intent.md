# Intent

## Проблема

Мелкие задачи, идеи, мини-проекты и цели карьерного роста разбросаны по заметкам и голове.
Крупную абстрактную цель («подтянуть Go», «выпустить пет-проект») трудно разложить на шаги,
а когда шаги есть, непонятно, за что браться сейчас.

## Идея

- Агент (Claude и другие MCP-клиенты) по правилам из скилла декомпозирует абстрактную задачу
  в атомарные задачи и раскладывает их по дереву папок.
- Человек смотрит, что делать дальше, и отмечает прогресс через веб, Flutter-приложение или Telegram-бота.
- Приоритет считается из положения задачи в дереве: произведение весов по пути от выбранной папки.

## Для кого

Сначала — для автора. Архитектура сразу многопользовательская (у каждого своё дерево),
чтобы сервис можно было открыть для всех без переписывания.

## Принципы

- Агент — полноправный клиент: MCP-тулы проектируются под его задачи, а не под CRUD.
- Одна бизнес-логика для всех клиентов: FastAPI и MCP — тонкие адаптеры над одними сервисами.
- Открытый проект под AGPL-3.0.

## Что НЕ делаем (пока)

- Шаринг папок и совместную работу — модель допускает, но не реализуем (ADR 0005).
- Дедлайны, напоминания, повторяющиеся задачи, календарь.
- Свой OAuth-сервер: для внешних клиентов будет внешний IdP, до этого — personal access tokens.
- Встроенный LLM на бэкенде: декомпозицию делает агент пользователя, бэкенд только хранит и считает.
