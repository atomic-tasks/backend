# Задачи

- [x] **Домен: `Weight`, статусы, `Folder`, `Task`, ошибки.**
  Готово: unit-тесты на валидацию веса, цикл при переносе, защиту корня, `done` с открытым содержимым,
  открытие под `done`-предком, создание и перенос в неактивную папку, удаление непустой папки без `recursive`.
- [x] **Таблицы, маппинг, миграция 0002** (с корнями существующим пользователям).
  Готово: `alembic upgrade head` и `downgrade base` на чистой базе и на базе с пользователями проходят;
  второй корень у пользователя вставить нельзя.
- [x] **Порты и репозитории** `FolderRepository`, `TaskRepository`; `AccessPolicy` и `OwnerAccessPolicy`.
  Готово: integration-тест CTE на Postgres — `path_to_root`, `count_open_descendants`, `count_children`
  на дереве из 3–4 уровней; mypy и lint-imports чистые.
- [x] **Корень при создании пользователя** в `UserService` и `IdentityService`.
  Готово: integration-тест — новый пользователь (CLI и первый вход) получает ровно один корень.
- [x] **FolderService.** Готово: integration-тест — перенос с циклом отклоняется, `recursive`-удаление
  сносит поддерево, `read`-токен не меняет данные.
- [x] **TaskService.** Готово: mypy и lint-imports чистые; правила задач покрыты unit-тестами домена.
- [x] **Изоляция.** Готово: integration-тест — пользователь A не читает, не меняет, не переносит и не удаляет
  папки и задачи B и не может создать или перенести что-то в папку B (везде «не найден»).
- [x] **Документация.** `docs/architecture.md` (корень, правила статусов), статус спеки.
