# domain

- Только stdlib. Никаких SQLAlchemy, pydantic, FastAPI, dishka (проверяется `lint-imports`).
- Сущности — dataclass'ы с методами, которые сами охраняют свои инварианты
  (например, папка не закрывается, пока в ней есть открытые задачи — решение принимает сервис,
  но проверка формулируется здесь).
- Ошибки — подклассы `DomainError` из `exceptions.py`, с понятным текстом: его увидит агент через MCP.
- Енамы статусов — `StrEnum`. Новый статус не требует миграции, но требует обновить правила переходов.
- Value objects неизменяемы (`frozen=True`) и валидируются в `__post_init__`.
- Вес — `Weight` в диапазоне 0.5–2.0, по умолчанию 1.0 (см. ADR 0003).
