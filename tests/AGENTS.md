# tests

Тест пишется, только если ошибка в этом месте дорогая или неочевидная.

Пишем:
- `unit/` — доменные правила: цикл при переносе папки, закрытие папки с открытыми задачами,
  создание задачи в неактивной папке, валидация весов. Без БД, быстрые.
- `integration/` — рекурсивные CTE на реальном Postgres (testcontainers): расчёт приоритета,
  отсечение неактивных веток, сортировка, защита от циклов.
- `e2e/` — изоляция пользователей: юзер A не видит и не меняет данные юзера B через FastAPI и MCP.

Не пишем: тесты CRUD-роутов, pydantic-схем, маппинга, геттеров — они либо тривиальны, либо покрыты выше.

Без моков БД: всё, что касается SQL, проверяется на настоящем Postgres.
