---
name: new-spec
description: Создать спеку новой фичи в docs/specs по шаблону (spec.md, plan.md, tasks.md). Использовать перед реализацией любой новой фичи или заметного изменения поведения.
---

1. Найди следующий номер: максимальный `NNNN` в `docs/specs/` + 1, четыре цифры.
2. Создай `docs/specs/NNNN-<kebab-name>/` и скопируй туда три файла из `docs/specs/_template/`.
3. Заполни `spec.md` из того, что сказал пользователь. Чего не хватает — спроси, не выдумывай.
   Раздел «Вне рамок» обязателен.
4. Сверься с `docs/roadmap.md` (раздел «Решения, уже принятые»), `docs/intent.md` и `docs/adr/`. Если фича противоречит им — скажи об этом до плана.
5. `plan.md`: какие слои и файлы затронуты, новые порты, миграции, MCP-тулы и эндпоинты.
6. `tasks.md`: шаги по 15–60 минут работы, каждый с критерием готовности. Тесты — только по `tests/AGENTS.md`.
7. Покажи пользователю спеку и план. Реализацию не начинай без его подтверждения.
